# WantTrade 다운로드

WantTrade는 mercury용 Trading MCP·DevTool MCP를 Claude Code, Claude Desktop 같은 AI 도구에 연결해 주는 Windows 프로그램입니다. 3.0.0부터는 한국투자증권(KIS) 모의투자에도 붙을 수 있습니다.

이 저장소에는 **설치 파일과 사용 설명서만** 올라옵니다. 소스 코드는 공개하지 않습니다.

## 설치

1. [최신 릴리스](../../releases/latest)에서 `WantTrade-Setup-<버전>.exe`를 내려받습니다.
2. 실행하면 바로 설치되고 WantTrade가 열립니다. 관리자 권한은 필요 없습니다.
3. Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요. 코드 서명 인증서가 아직 없어서 나오는 경고입니다.

지원 환경: Windows 10/11 (64비트)

설치한 뒤 설정 순서, 로그인, 주문 승인, 문제 해결 방법은 [사용 설명서](GUIDE.md)를, AI가 쓸 수 있는 기능은 [도구 목록](TOOLS.md)을 보세요.

## 3.0.1에서 바뀐 점

- KIS 모의투자에서 산 미국 주식이 보유 종목에 보이지 않던 것을 고쳤습니다.
- KIS 모의투자에서 국내 주식도 장 시간(평일 08:30~15:30) 밖이면 승인 창 전에 막습니다.
- 자세한 것은 사용 설명서의 [3.0.0에서](GUIDE.md#300에서)를 보세요.

## 3.0.0에서 바뀐 점

- **KIS 모의투자에 붙을 수 있습니다.** 톱니바퀴 → Trading 설정의 접속 서버에서 **KIS 모의투자**를 고르고, KIS Developers에서 받은 모의투자용 앱키·앱시크릿과 모의 계좌번호로 로그인합니다. 모의투자만 되고 실계좌는 붙지 않습니다.
- **KIS 모의투자에서는 미국 주식도 주문할 수 있습니다.** 가격은 달러이고, 주문 한도는 환율로 원화로 바꿔 국내 주문과 합쳐 셉니다. 미국 장 시간에만 주문됩니다.
- mercury 서버(스테이징)는 그대로 쓸 수 있습니다. 접속 서버를 바꾸지 않았다면 업데이트해도 달라지는 것이 없습니다.
- KIS 모의투자에 없는 기능(뉴스·공시, 배당, 조건검색, 미국 주식 호가 등)은 쓸 수 없습니다. 자세한 것은 사용 설명서의 [KIS 모의투자](GUIDE.md#kis-모의투자)를 보세요.

| 항목 | 1.3.x | 2.x |
| --- | --- | --- |
| 화면 | 설정 화면 하나 | 로그인 화면 → 홈 화면. 설정은 톱니바퀴 |

| 계좌 | 설정에 넣은 계좌 하나 | 여러 개면 홈 화면에서 고름 |

| 실시간 조건·자동 주문 | 없음 | 실시간 조건 주문(오르면·내리면·트레일링 스탑, 주문 후 유지·제거), 분할·그리드 주문. 실시간 조건 주문은 주문 나갈 때마다 창에서 승인(설정으로 등록할 때만), 분할·그리드는 등록할 때 한 번 승인 |
| 직접 만든 프로그램 | 없음 | 이 PC 안에서 같은 기능을 씀 (주문은 기본으로 창에서 승인) |
| 주문 승인 | 실계좌만 창에서 승인 | 모의·실계좌 모두 창에서 승인 |
| 모드 | 조회 전용 / 모의 / 실계좌 | 모의 / 실계좌 |
| 주문 허용 종목 | 꼭 넣어야 함 | 칸이 없어짐 (주문마다 창에서 승인) |

이전 버전을 쓰던 분은 사용 설명서의 [이전 버전에서 올라왔다면](GUIDE.md#이전-버전에서-올라왔다면)을 먼저 보세요. 2.2.0에서 화면이 바뀌었고, 2.3.0에서 정정·주문 내역·차트·백테스트 같은 기능이 다시 생겼습니다. 2.4.0에서 실시간 조건 주문·분할·그리드 주문·조건검색과 초당·분당 주문 수·하루 최대 손실 한도가 생겼습니다. 2.4.2부터 실시간 조건 주문은 조건이 맞아 주문이 나갈 때도 창에서 승인합니다(설정으로 바꿀 수 있음). 3.0.0에서 KIS 모의투자 연결이 생겼습니다.

## 업데이트

설치한 뒤에는 따로 내려받을 필요가 없습니다. WantTrade가 시작할 때와 켜져 있는 동안 4시간마다 이 저장소에서 새 버전을 확인해 자동으로 받아 둡니다.

- 장 시간(평일 09:00~20:00)에는 앱을 닫아도 설치하지 않습니다.
- 장 시간이 아닐 때 앱을 닫거나 다음에 실행할 때 설치합니다.
- 홈 화면 위쪽의 "재시작하여 업데이트"를 누르면 바로 설치할 수도 있습니다.
