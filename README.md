# WantTrade 다운로드

WantTrade는 mercury용 Trading MCP·DevTool MCP를 Claude Code, Claude Desktop 같은 AI 도구에 연결해 주는 Windows 프로그램입니다. 3.0.0부터는 한국투자증권(KIS) 모의투자에도 붙을 수 있습니다.

이 저장소에는 **설치 파일과 사용 설명서만** 올라옵니다. 소스 코드는 공개하지 않습니다.

## 설치

1. [최신 릴리스](../../releases/latest)에서 `WantTrade-Setup-<버전>.exe`를 내려받습니다.
2. 실행하면 바로 설치되고 WantTrade가 열립니다. 관리자 권한은 필요 없습니다.
3. Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요. 코드 서명 인증서가 아직 없어서 나오는 경고입니다.

지원 환경: Windows 10/11 (64비트)

설치한 뒤 설정 순서, 로그인, 주문 승인, 문제 해결 방법은 [사용 설명서](GUIDE.md)를, AI가 쓸 수 있는 기능은 [도구 목록](TOOLS.md)을 보세요.

## 3.2.0에서 바뀐 점

- **실시간 조건 주문·분할·그리드 주문은 블록 전략으로 바뀌었습니다.** AI에게 예전처럼 말하면("5% 오르면 사 줘", "평단에서 5% 빠지면 팔아 줘", "체결되면 한 주 더 사 줘") 같은 일을 하는 블록 전략을 만들어 승인을 요청합니다. 예전 방식으로는 새로 걸 수 없고, 이미 걸어 둔 것은 끝날 때까지 그대로 돕니다.
- **블록 전략의 주문도 "주문마다 승인"을 따릅니다.** 기본은 조건이 맞아 주문이 나갈 때마다 창에서 승인입니다(3.1.0에서는 창 없이 나갔습니다). Trading 설정의 **블록 전략·실시간 조건 주문 → 주문 승인**에서 바꿉니다.
- 블록이 많아졌습니다. MACD·볼린저밴드·스토캐스틱·일목균형표 같은 지표, 1·3·5·10·15·30·60분봉·주봉·월봉, 거래량·거래대금, 체결 한 건의 체결량으로 조건을 만들 수 있습니다.
- KIS 모의투자의 **미국 주식**도 블록 전략이 됩니다(금액은 달러).
- 같은 종목에 전략을 여러 개 걸 수 있습니다. 승인 창에 같은 종목에 돌고 있는 전략 수가 나옵니다.
- 홈 화면의 블록 전략 목록이 짧아졌습니다. 누르면 펼쳐지고, 기간이 끝난 전략은 아래에 접혀 **모두 지우기**로 한꺼번에 지웁니다.
- **DevTool MCP**가 바뀌었습니다. 예전 TR 문서 도구 8개 대신 도구 3개로 Open API 기능·오류·코드값을 찾고, 내 프로그램을 로컬 Open API에 붙이는 법을 알려 줍니다. .mcpb 파일로 설치했다면 새로 만들어 다시 설치하세요. [도구 목록](TOOLS.md#devtool-mcp) 참고.
- 자세한 것은 사용 설명서의 [블록 전략](GUIDE.md#블록-전략)을 보세요.

## 3.1.0에서 바뀐 점

- **블록 전략이 생겼습니다.** "HMM 현재가가 20일 이동평균을 넘으면 10만 원어치 사 줘, 하루 한 번만"처럼 말하면, AI가 미리 만들어 둔 블록(현재가, 이동평균, RSI, 넘으면, 하루 몇 번, 매수·매도 등)을 이어 전략을 만듭니다. WantTrade 창에서 승인하면 앱이 가격을 지켜보다가 조건이 맞을 때 주문합니다.
- 승인 창의 문장과 최대 매수 금액은 앱이 전략에서 직접 만듭니다. AI가 쓴 설명은 보여 주지 않습니다.
- 기간, 1회 금액, 횟수, 총 매수 한도, 주문 가격 가운데 말하지 않은 것이 있으면 AI가 먼저 물어봅니다.
- 승인한 뒤에는 주문마다 다시 묻지 않습니다. 주문 한도와 긴급 정지는 그대로 걸리고, 한도에 5번 이어서 걸리면 전략이 멈춥니다.
- 홈 화면에 **블록 전략** 카드가 생겼습니다. 상태, 오늘 실행 횟수, 최근 주문·거절을 보고 정지·다시 켜기·지우기를 합니다.
- 지금은 mercury와 KIS 모의투자의 국내 주식에서 됩니다. 실시간 조건 주문·분할·그리드 주문은 그대로 쓸 수 있습니다.
- 자세한 것은 사용 설명서의 [블록 전략](GUIDE.md#블록-전략)을 보세요.

## 3.0.1에서 바뀐 점

- KIS 모의투자에서 산 미국 주식이 보유 종목에 보이지 않던 것을 고쳤습니다.
- KIS 모의투자에서 국내 주식도 장 시간(평일 08:30~15:30) 밖이면 승인 창 전에 막습니다.
- 자세한 것은 사용 설명서의 [3.0.0에서](GUIDE.md#300에서)를 보세요.

## 3.0.0에서 바뀐 점

- **KIS 모의투자에 붙을 수 있습니다.** 톱니바퀴 → Trading 설정의 접속 서버에서 **KIS 모의투자**를 고르고, KIS Developers에서 받은 모의투자용 앱키·앱시크릿과 모의 계좌번호로 로그인합니다. 모의투자만 되고 실계좌는 붙지 않습니다.
- **KIS 모의투자에서는 미국 주식도 주문할 수 있습니다.** 가격은 달러이고, 주문 한도는 환율로 원화로 바꿔 국내 주문과 합쳐 셉니다. 미국 장 시간에만 주문됩니다.
- mercury 서버(스테이징)는 그대로 쓸 수 있습니다. 접속 서버를 바꾸지 않았다면 업데이트해도 달라지는 것이 없습니다.
- KIS 모의투자에 없는 기능(뉴스·공시, 배당, 조건검색, 미국 주식 호가 등)은 쓸 수 없습니다. 자세한 것은 사용 설명서의 [KIS 모의투자](GUIDE.md#kis-모의투자)를 보세요.

| 항목 | 1.3.x | 2.x |
| --- | --- | --- |
| 화면 | 설정 화면 하나 | 로그인 화면 → 홈 화면. 설정은 톱니바퀴 |
| 로그인 | 설정에 계좌 정보(`user_uid`, `acnt_cd`)를 넣음 | 앱에서 이름·생년월일·휴대폰번호로 로그인 |
| 계좌 | 설정에 넣은 계좌 하나 | 여러 개면 홈 화면에서 고름 |
| AI가 쓰는 도구 | 23개 | 3개 (기능 찾기·설명 보기·부르기). 이 3개로 기능 32개(잔고·주문·정정·내역·시세·차트·조건검색·백테스트·실시간 조건 주문·자동 주문·블록 전략 등)를 씀 |
| 실시간 조건·자동 주문 | 없음 | 블록 전략으로 만듦(오르면·내리면, 평단 기준 손절·익절, 트레일링 스탑, 분할·그리드, 지표 조건). 등록할 때 창에서 승인하고, 주문 나갈 때도 창에서 승인(설정으로 등록할 때만) |
| 직접 만든 프로그램 | 없음 | 이 PC 안에서 같은 기능을 씀 (주문은 기본으로 창에서 승인) |

| 모드 | 조회 전용 / 모의 / 실계좌 | 모의 / 실계좌 |
| 주문 허용 종목 | 꼭 넣어야 함 | 칸이 없어짐 (주문마다 창에서 승인) |

이전 버전을 쓰던 분은 사용 설명서의 [이전 버전에서 올라왔다면](GUIDE.md#이전-버전에서-올라왔다면)을 먼저 보세요. 2.2.0에서 화면이 바뀌었고, 2.3.0에서 정정·주문 내역·차트·백테스트 같은 기능이 다시 생겼습니다. 2.4.0에서 실시간 조건 주문·분할·그리드 주문·조건검색과 초당·분당 주문 수·하루 최대 손실 한도가 생겼습니다. 2.4.2부터 실시간 조건 주문은 조건이 맞아 주문이 나갈 때도 창에서 승인합니다(설정으로 바꿀 수 있음). 3.0.0에서 KIS 모의투자 연결이, 3.1.0에서 블록 전략이 생겼고, 3.2.0에서 실시간 조건·분할·그리드 주문이 블록 전략으로 바뀌었습니다.

## 업데이트

설치한 뒤에는 따로 내려받을 필요가 없습니다. WantTrade가 시작할 때와 켜져 있는 동안 4시간마다 이 저장소에서 새 버전을 확인해 자동으로 받아 둡니다.

- 장 시간(평일 09:00~20:00)에는 앱을 닫아도 설치하지 않습니다.
- 장 시간이 아닐 때 앱을 닫거나 다음에 실행할 때 설치합니다.
- 홈 화면 위쪽의 "재시작하여 업데이트"를 누르면 바로 설치할 수도 있습니다.
